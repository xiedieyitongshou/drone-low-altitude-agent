# Day 143 前端构建与兼容检查

## 目标

确认 Agent 化前端改造没有破坏现有用户界面，并把前端 lint/build 接入 CI。

## CI 检查

GitHub Actions 已新增 `Frontend lint and build` job：

```bash
cd frontend
npm ci
npm run lint
npm run build
```

CI 环境固定为 Node 24，并使用 `frontend/package-lock.json` 缓存 npm 依赖。

## 本地验证

本地已执行：

```bash
npm ci
npm run lint
npm run build
```

结果：

```text
lint passed
build passed
```

`npm ci` 当前会提示依赖漏洞和 npm 配置 warning，但不影响 Day 143 的 lint/build 门禁。后续如需处理安全审计，应单独评估 `npm audit` 的升级影响。

## 关键页面兼容

已检查路由入口：

- `/`：健康状态页
- `/agent`：Agent 对话页
- `/evaluate`：单点评估页
- `/recommend`：推荐窗口页
- `/compare`：多地点比选页
- `/tasks`：任务单页
- `/history`：历史记录页
- `/profile`：Profile 设置页
- `/admin`、`/admin/users`、`/admin/conversations`、`/admin/knowledge`：管理员入口

普通业务页面仍通过 `ProtectedRoute` 要求登录，管理员页面通过 `requiredRole="admin"` 限制访问，`super_admin` 仍兼容管理员权限。

RAG evidence 展示入口：

- `frontend/src/components/KnowledgeAdvicePanel.tsx`
- `frontend/src/pages/AgentPage.tsx`
- `frontend/src/pages/HistoryPage.tsx`

Trace 和 RAG evidence 都是可选展示：缺少 `trace_id`、`knowledge_snippets` 或 `retrieval_metadata` 时，页面会显示空态或不渲染对应面板，不影响普通用户主流程。

Day 143 的前端构建与兼容检查已接入 CI。当前主要演示路径具备构建级别保障，后续若需要更强的浏览器级验证，应在独立任务中补充端到端测试。
