# 服务器部署说明

## 部署定位

本项目的线上环境定位为求职项目演示环境，不作为生产级低空作业安全系统。

当前服务器部署采用轻量方案：

- 云厂商：阿里云
- 服务器类型：Linux 服务器
- 系统镜像：Alibaba Cloud Linux 4
- 推荐规格：2 vCPU / 2 GiB 内存 / 40 GiB 系统盘
- 部署方式：Docker Compose 手动部署
- 数据库：先使用 SQLite 文件卷，后续按负载和数据量迁移 PostgreSQL
- 缓存与会话：Redis
- 反向代理：Nginx

公开仓库不记录真实公网 IP、SSH 密钥、管理员账号、演示账号密码、API key、JWT 密钥和数据库备份。

## 服务器目录规划

当前服务器侧目录：

```text
/opt/drone-low-altitude-agent/
  app/              # 后续放置 GitHub 拉取的项目代码
  config/           # 服务器本地配置，占位模板和 Nginx 草案
  config/nginx/     # Nginx 站点配置草案
  data/             # SQLite 数据文件和持久化数据
  logs/             # 项目日志
  backups/          # 服务器本地备份

/var/log/drone-low-altitude-agent/
/var/backups/drone-low-altitude-agent/
```

注意：

- `config/`、`backups/` 和 `/var/backups/drone-low-altitude-agent/` 应保持服务器本地私有。
- 真实 `.env`、数据库备份、证书私钥和临时演示账号信息不提交 Git。
- GitHub 仓库只保留 `.env.example`、`.env.production-demo.example` 或占位模板。

## 基础安装命令

Alibaba Cloud Linux 4 可使用系统源安装基础依赖：

```bash
dnf makecache -y
dnf install -y git docker docker-compose-plugin nginx curl wget tar gzip vim-minimal
systemctl enable --now docker
systemctl enable nginx
```

2 GiB 内存规格建议配置 swap，降低 Docker build 或前端构建时内存不足的概率：

```bash
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

## 公网暴露面

推荐公网只开放：

- SSH：仅维护使用，建议限制来源 IP 或至少使用密钥登录
- HTTP：80，用于 Nginx 和证书申请
- HTTPS：443，用于正式演示入口

不应直接公网开放：

- Redis
- SQLite 数据目录
- 后端容器内部端口
- 管理员账号信息
- Swagger/OpenAPI 文档入口
- 压测入口和压测账号

## 最小备份方案

已在服务器创建备份脚本：

```text
/usr/local/sbin/backup-drone-agent.sh
```

备份内容：

- `data/drone_agent.db`
- `data/knowledge/index/`
- 服务器真实 `.env`

备份目录：

```text
/var/backups/drone-low-altitude-agent/YYYYMMDD-HHMMSS/
```

备份文件权限：

```text
600 root:root
```

手动执行：

```bash
/usr/local/sbin/backup-drone-agent.sh
```

当前策略：

- 备份只保存在服务器私有目录
- 备份文件不提交 GitHub
- 默认保留最近 14 天目录，脚本会清理更旧的备份目录

恢复 SQLite 数据库时，应先停止写入或停止容器：

```bash
cd /opt/drone-low-altitude-agent/app
docker compose stop app
cp /var/backups/drone-low-altitude-agent/<backup-dir>/drone_agent.db data/drone_agent.db
chmod 600 data/drone_agent.db
docker compose up -d app
```

恢复 `.env` 后需要重启相关容器：

```bash
cp /var/backups/drone-low-altitude-agent/<backup-dir>/env.backup .env
chmod 600 .env
docker compose up -d --force-recreate app frontend
```
