## 演示路径

推荐演示顺序：

1. 登录前端控制台，打开 Agent 页面。
2. 输入“帮我判断明天下午深圳湾适不适合巡航”，展示自然语言解析、工具调用和最终结论。
3. 追问“那换成后天上午呢”，展示多轮上下文继承和字段覆盖。
4. 输入多地点比选问题，展示业务工具编排。
5. 打开 Trace 面板，解释 plan、tool_call、tool_result、fallback 和 final_response。
6. 打开知识库或建议结果，说明 RAG 只增强解释，不改变规则结论。
7. 切换管理员页面，展示用户治理、统计和会话审计。
8. 展示 GitHub Actions、测试命令和 Eval 报告，说明质量门禁。

## 当前边界

- 项目是低空作业气象决策原型，不是生产级航空安全系统。
- 天气准确性依赖第三方服务。
- 当前规则阈值服务于工程验证，不等同于监管审批标准。
- RAG 知识库是样例知识库，不是实时权威政策库。
- Docker Compose 适合本地联调和服务器部署前验证，生产化还需要 HTTPS、PostgreSQL、监控、备份和反向代理。
